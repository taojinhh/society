# 통합사회 만점 독학

통합사회1·2를 개념부터 실전까지 혼자 익히는 웹 기반 독학 프로그램.
고졸 검정고시 만점을 기준으로 설계했지만, 범위와 개념이 같으므로
일반 고등학교 통합사회 수업·내신 공부에도 그대로 쓸 수 있다.
`통합사회1·2 검정고시 만점 독학 프로그램 개발 기획서`의 기능 요구사항을 구현했다.

## 실행 방법

설치·빌드·인터넷 연결이 필요 없다. **`index.html`을 더블클릭**하면 바로 열린다.

휴대폰에서 쓰려면 폴더째 복사해 옮기거나, PC에서 아래 명령으로 서버를 띄우고
같은 와이파이의 휴대폰에서 `http://<PC의 IP>:8777` 로 접속한다.

```bash
python -m http.server 8777
```

학습 기록은 브라우저의 localStorage에 저장된다. 기기·브라우저마다 따로 쌓이므로
**한 기기에서 꾸준히 쓰는 것**을 권한다. (초기화: 리포트 → 학습 기록 초기화)

단원 체계는 **비상교육 『통합사회1·2』(이영호 외, 2022 개정)** 의 대단원·중단원을 그대로 따랐고,

|---|---|---|
| 필수 | 1부 기본개념 학습 (배우기 → 확인 → 통과) | 하단 탭 → 1부 개념 |
| 추가 | 강의 만화 (영상 내용을 컷 만화로) | 1부 배우기 화면 맨 위 |
| 필수 | 개념·대비·사례 지도 (숙달도 5색) | 홈 → 단원 → 개념 카드 |
| 필수 | 개념 매칭 게임 (이름 카드 ↔ 뜻 카드) | 홈 → 개념 매칭 게임 / 단원 화면 |
| 필수 | 사례 분류 게임 (드래그 / 탭, 오답 시 한 줄 해설) | 대비표 → 분류 게임 |
| 필수 | 개념 즉답 퀴즈 (20초 제한, 느리면 자동 불안정) | 홈 → 5분 즉답 퀴즈 |
| 필수 | 간격반복 큐 (1·3·7일, 다른 사례로 재출제) | 홈 → 복습 큐 |
| 필수 | 실전 모의고사 (30분, 25문항, OMR, 문항별 시간) | 하단 탭 → 모의고사 |
| 권장 | 인터랙티브 자료 (기후 그래프·인구 피라미드 슬라이더·지도 클릭) | 홈 → 자료 해석 훈련 |
| 권장 | 시사 사례 카드 | 개념 카드 안에 `시사` 태그로 표시 |
| 권장 | AI 튜터 (띄어쓰기·줄임말·질문형을 모두 알아듣는다) | 홈 → 튜터에게 묻기 |
| 선택 | 배지·연속 학습일 | 홈 상단 / 리포트 |
| 추가 | 오답 노트 (문항 통째로 보관, 모아 풀기) | 하단 탭 → 오답 노트 |
| 추가 | 내 학습 단계 (5단계 체크리스트) | 하단 탭 → 내 단계 |
| 추가 | 핵심 그림 (개념 188개가 저마다 다른 그림) | 개념 카드 / 단원 / 대비표 |

추가로 구현한 것: **단원 보스전**(5문항 전부 정답 시 통과), **발문 핵심어 터치 드릴**
(‘옳지 않은’을 놓치는 습관 교정), **내 학습 단계 체크리스트**, **보호자용 리포트**.

어느 화면에서든 **오른쪽 위 ‘홈’ 버튼**이나 화면 아래 탭바로 홈에 바로 갈 수 있다.
왼쪽 위 ‘←’는 한 단계 위(단원·대비표 등)로 돌아간다.
모의고사 중에는 ‘나가기’로 중단할 수 있으며, 이때 푼 내용은 채점되지 않는다.

## 두 파트로 나뉜 구성

개념을 모르는 채로 문제부터 풀면 틀린 이유를 알 수 없다. 그래서 순서를 둘로 나눴다.

### 1부 · 기본개념 학습 (하단 탭 → 1부 개념)

개념 188개를 **하나씩 정확히** 익히는 과정이다. 개념마다 3단계를 거친다.

| 단계 | 하는 일 |
|---|---|
| 1 배우기 | **만화** → 그림 → 정의 → 이 말이 보이면 이 개념(판별 단서) → 함정 → 사례 2개 |
| 2 확인 | 그 개념만 묻는 문제 2문항 (뜻↔이름, 사례 판별) |
| 3 통과 | **둘 다 맞혀야** ✓ 배움 완료 도장. 틀리면 ‘개념 다시 보기’로 돌아간다 |

- 통과한 개념에는 카드에 ✓ 가 붙고, 단원·전체 진도가 올라간다
- ‘이어서 배우기’는 **아직 안 배운 첫 개념**으로 바로 데려간다
- 확인 문제의 정답/오답은 숙달도와 복습 큐에도 그대로 반영된다
- 한 단원을 다 배우면 곧바로 **단원 보스전**으로 넘어간다

### 2부 · 시험 만점 도전 (하단 탭 → 2부 도전)

점수를 올리는 훈련을 모아 둔 곳이다.

- **개념 갈라내기** — 대비표 50쌍, 사례 분류 게임, 개념 매칭 게임, 20초 즉답 퀴즈
- **자료와 발문** — 자료 해석 훈련 10종, 발문 터치 드릴
- **실전** — 30분 25문항 모의고사, 오답 노트, 내 학습 단계

1부 진행률이 50% 미만이면 2부 첫 화면에 **“1부를 먼저 하세요”** 안내가 뜬다.
막지는 않는다 — 미리 둘러보는 것은 자유다.

## 강의 만화

강의 영상의 설명을 **컷 만화**로 옮겨 1부 `배우기` 화면 맨 위에 넣는다.
정의 글보다 먼저 만화를 보게 해서, 개념이 머리에 그림으로 남게 하는 것이 목적이다.

- 한 컷씩 넘겨 보는 뷰어다(‹ 이전 / 다음 ›, 아래 점을 눌러 바로 이동)
- 점 하나가 **노란 테두리**로 표시되는데, 그 개념의 핵심 컷이다
- 만화 제목은 **다루는 범위**를 적는다. 개념 이름을 제목으로 쓰면
  그 개념만의 내용으로 오해되므로, 여러 개념을 함께 다룬다는 안내 문구도 함께 띄운다
- 컷 아래에 내레이션 한 줄, 맨 아래에 출처 영상이 적힌다
- 그림·말풍선·인물 모두 SVG라 용량이 없고 인터넷 없이도 뜬다
- 등장인물은 **만화 내용에 맞춰 만든 SVG 캐릭터 7명**이다.
  얼굴은 점 두 개와 입 하나로만 그린다 — 안경·속눈썹 같은 잔선을 넣지 않는다

| 키 | 캐릭터 | 알아보는 표시 | 대본의 색 이름 |
|---|---|---|---|
| `a` | 시간 탓을 하는 사람 | 파란 옷 · 가슴에 **시계** | `blue` |
| `b` | 장소 탓을 하는 사람 | 초록 옷 · 묶은 머리 · 가슴에 **지도 핀** | `green` |
| `c` | 제도 탓을 하는 사람 | 주황 옷 · 야구모자 · 가슴에 **관공서** | `amber` |
| `d` | 옳고 그름을 따지는 사람 | 분홍 옷 · 양갈래 · 가슴에 **하트** | `red` |
| `phil` | 아리스토텔레스 | 월계관 · 흰 수염 · 토가 | `purple` |
| `monk` | 석가모니 | 민머리 · 정수리 융기 · 주황 법의 | — |
| `sun` | 정약용 | 갓 · 수염 · 흰 도포 | — |

대본에는 `c: 'blue'`처럼 색 이름으로 적으면 되고, 엔진이 해당 캐릭터로 바꿔 그린다.
사상가처럼 특정 인물이 필요하면 `ch: 'phil'`로 직접 지정한다.
`mood`는 `calm` · `talk` · `happy` · `worry` 네 가지이고, 눈과 입 모양만 바뀐다.
`assets/char-a~d.png`(직접 그린 그림)로 바꿔 그리고 싶으면
`app/comic.js` 맨 위의 `USE_CAST`를 `true`로 둔다.

#### 컷 안의 그림 — 아이콘과 상세 삽화

컷에 그림을 넣는 길은 두 가지다.

- `props` — `app/art-concepts.js`의 24px 픽토그램을 키워 쓴다. 넷을 나열해 비교하는 컷에 쓴다.
- `arts` — `app/comic-art.js`의 **전용 상세 삽화**를 쓴다.
  구조를 봐야 이해되는 컷(온실 효과 단면, 판이 부딪히는 단면, 지형 단면, 소득·행복 그래프 등)은 이쪽이다.

```js
arts: [{ k: 'greenhouse', x: 170, y: 102, w: 320, h: 160 }]
arts: [{ k: 'regionmap', x: 170, y: 72, w: 326, h: 100, o: { hi: ['eu'] } }]
```

`o`는 그림에 넘기는 옵션이다. `regionmap`은 `o.hi`에 적힌 권역만 색으로 칠하고 이름을 붙인다
(`arc` 북극 · `ang` 앵글로 아메리카 · `lat` 라틴 아메리카 · `eu` 유럽 ·
`dry` 건조 · `af` 아프리카 · `as` 아시아 · `oc` 오세아니아).

`x, y`는 컷 안에서 그림의 **중심**, `w, h`는 들어갈 상자다.
그림은 자기 고유 크기를 갖고 있고, 비율을 지킨 채 상자에 맞춰 줄어든다.

### 만화를 추가하는 방법

영상의 **자막(스크립트) 텍스트**가 있으면 만화로 옮길 수 있다.
(영상 파일 자체는 읽을 수 없으므로 자막·캡처·요약 중 하나가 필요하다.)

`data/comics.js`에 대본을 적는다. 컷 하나는 배경 + 인물 + 소품 + 말풍선 + 내레이션이다.

```js
'u3-nature': {
  title: '자연을 보는 두 가지 눈',
  src: '출처 영상 제목',
  concepts: ['c309', 'c310'],        // 이 만화를 쓰는 개념
  focus: { c309: 2, c310: 4 },       // 개념별 핵심 컷 번호(0부터)
  panels: [
    { scene: 'field',                                   // 배경
      people: [{ x: 80, y: 182, c: 'blue', mood: 'talk', s: .9 }],
      props:  [{ g: 'tree', x: 250, y: 110, s: 2.4 }],  // 픽토그램 재사용
      bubbles:[{ x: 90, y: 50, w: 150, t: '이 숲은 우리한테 쓸모가 있어야 가치가 있지.' }],
      labels: [{ x: 170, y: 200, t: '인간 중심주의' }],
      narr: '인간의 이익을 기준으로 자연을 본다.' }
  ]
}
```

| 항목 | 쓸 수 있는 값 |
|---|---|
| `scene` | `boat` `deck` `sea` `room` `city` `field` `plain` |
| `people[].c` | `blue`(a) `green`(b) `amber`(c) `red`(d) `purple`(phil) — 캐릭터 지정 |
| `people[].ch` | 캐릭터를 직접 지정 (`a` `b` `c` `d` `phil` `monk` `sun`) |
| `people[].mood` | 벡터 인물일 때만: `calm` `talk` `happy` `worry` |
| `props[].g` | `app/art-concepts.js`의 픽토그램 110종 이름 |
| `bubbles[].tail` | `down`(기본) / `up` |

말풍선 글자는 폭에 맞춰 자동으로 줄바꿈된다. 인물·소품·글자가 겹치지 않는지는
만들고 나서 화면으로 확인하는 편이 빠르다.

### 영상과 교과서가 어긋날 때

행복 영상은 **“행복은 남과 비교하는 게 아니라 자기 마음속에서 찾는 것”**으로 끝난다.
삶의 조언으로는 옳지만, 검정고시에서는 **“행복은 전적으로 개인의 마음먹기”가 오답**이다.
교과서는 질 높은 정주 환경·경제적 안정·민주주의의 발전·도덕적 실천이라는
**사회적 여건**을 함께 요구한다.

그래서 이 만화의 마지막 컷은 `📘 교과서 보충`으로 **표시를 달아** 덧붙였다.
영상 내용과 교과서 내용을 섞지 않고 구분해 두기 위해서다.
앞으로도 영상이 시험 범위를 덜 다루면 같은 방식으로 보충 컷을 붙인다.

## 개념 사이를 오가는 법

개념이 목록 글줄이 아니라 **누를 수 있는 카드**로 보인다.

- 단원 화면의 개념은 그림 조각 + 숙달도 점 + 뜻 두 줄 + **‘눌러서 공부하기 ›’** 가 붙은 카드다
- 개념을 보는 중에도 **화면 아래에 같은 단원의 개념 카드가 전부** 깔려 있어,
  뒤로 가지 않고 바로 다음 개념으로 넘어갈 수 있다 (지금 보는 개념은 파랗게 표시)
- 그 위에 **‹ 이전 개념 / 다음 개념 ›** 버튼이 있어 교과서 순서대로 쭉 읽어 나갈 수 있다

## 핵심 그림

글만 이어지면 읽기 힘드니 **개념 188개가 저마다 다른 그림 한 장**을 갖는다.
사진이 아니라 SVG로 그린 그림이라 용량이 없고 인터넷 없이도 뜬다.

- **개념 카드 188개 → 서로 다른 그림 188개** (완전히 같은 그림 0건, 자동 검사로 확인)
  - 자유권은 `국가 ✕ 열린 자물쇠`, 평등권은 `사람 = 저울`, 참정권은 `투표함`,
    청구권은 `침해 → 법봉`, 사회권은 `학교·근로·빵` — 다섯 기본권이 모두 다른 그림이다
  - 발명은 전구, 발견은 돋보기, 자극 전파는 `돋보기 → 전구`,
    문화 동화는 `우리 집 → ✕`, 병존은 `기와집 | 빌딩`, 융합은 `기와집 + 빌딩 → 새것`
- **단원 화면·대비표**에는 단원을 대표하는 큰 삽화 40종이 따로 들어간다
  (기후별 가옥, 저울, 발판 그림, 인구 피라미드 3형태 등)

만드는 방식은 **픽토그램 + 배치 틀 + 개념별 지정**의 조합이다.

| 파일 | 역할 |
|---|---|
| `app/art-concepts.js` | 픽토그램 110종(`G`), 배치 틀 5종(`T`), 개념별 지정 188개(`SPEC`) |
| `app/art.js` | 단원·대비표용 큰 삽화 40종 |
| `app/comic.js` | 만화 엔진 — 등장인물 7명, 말풍선, 배경 8종, 가슴 표식 |
| `app/comic-art.js` | 만화 컷 전용 상세 삽화 222종 (`ComicArt`) |
| `assets/char-a~d.png` | 예비 캐릭터 그림 (기본값은 꺼져 있다 — `USE_CAST`) |

배치 틀은 `one`(큰 그림 하나), `vs`(둘을 맞세움), `tiles`(2~4칸 나열),
`flow`(화살표로 잇기), `hub`(중심 + 가지) 다섯 가지다. 새 개념의 그림은 한 줄로 지정한다.

```js
// app/art-concepts.js 의 SPEC
c409: ['flow', [['house', '우리 문화'], ['cross', '사라짐']], '외래문화로 완전히 대체된다'],
c614: ['vs', ['capitol', '국가'], ['unlock', '간섭하지 마라'], '✕', '신체·종교·언론·재산의 자유'],
```

## 튜터에게 묻기

두 개념의 차이나 한 개념의 뜻을 그대로 물으면 대비표나 개념 카드로 답한다.
**띄어쓰기가 달라도, 줄여 말해도, 질문형으로 써도 찾는다.**

| 이렇게 쳐도 | 찾아 주는 것 |
|---|---|
| `사회구조` (띄어쓰기 없음) | 사회 구조 |
| `융합` (줄임말) | 문화 융합 |
| `청구권이 뭔가요` (질문형) | 청구권 |
| `시장실패와 정부실패 차이가 뭐야?` | 시장 실패 vs 정부 실패 대비표 |
| `자유권과 사회권` | 기본권 다섯 가지 대비표 |

판별 단서로도 찾으며, 못 찾으면 **비슷한 이름을 추천**해 준다.

## 오답 노트

문제를 틀리면 **문항이 통째로 저장된다.** 발문·선택지·내가 고른 답·정답·해설·자료(그래프·표)까지
그대로 남으므로, 모의고사를 끝내고 화면을 나가도 나중에 다시 볼 수 있다.

- **골라 보기** — 못 잡은 것만 / 전체, 단원별, 오답 원인별
- **틀린 문제만 모아 풀기** — 최대 10문항. 선택지 순서를 매번 섞어 위치 암기를 막는다
- **해결 기준** — 서로 다른 판에서 **2번 연속** 맞히면 ‘해결’로 바뀐다. 한 번 틀리면 다시 처음부터
- 각 문항에서 관련 개념 카드·대비표·자료 훈련으로 바로 이동할 수 있다
- 하단 탭의 ‘오답 노트’에 아직 못 잡은 문항 수가 배지로 뜬다

## 내 학습 단계

“내가 무엇을 했고 무엇을 안 했는지”를 5단계 **체크리스트**로 보여 준다(하단 탭 → 내 단계).
주차를 직접 입력하는 방식이 아니라, 실제 학습 기록에서 자동으로 계산된다.

| 단계 | 달성 조건 |
|---|---|
| 1. 진단 | 10개 단원을 한 번씩 맛보기(단원당 개념 3개 이상) |
| 2. 통합사회1 | **1부 개념 전부 배우기** · 보스전 5개 · 개념 70%를 ‘익힘’ 이상으로 |
| 3. 통합사회2 | **1부 개념 전부 배우기** · 보스전 5개 · 개념 70%를 ‘익힘’ 이상으로 |
| 4. 자료·실전 | 자료 10종 모두 풀기 · 모의고사 6회 · 3회 연속 100점 |
| 5. 마무리 | 대비 쌍 50개 완성 · 빨강 개념 0개 · 오답 노트 0개 |

각 줄에 현재 숫자(예: `3 / 5`)와 진행 막대, **‘하러 가기’ 버튼**이 붙어 있어
모자란 항목에서 바로 해당 화면으로 넘어갈 수 있다.

## 오답 원인 → 처방 연결

문항을 틀리면 원인을 고르게 하고, 곧바로 처방 화면으로 넘긴다.

| 원인 | 처방 | 이동 화면 |
|---|---|---|
| 개념 혼동 | 대비표 재학습 + 분류 게임 1판 | 해당 대비 쌍의 분류 게임 |
| 개념 모름 | 개념 카드 + 사례 2개 | 개념 카드 상세 |
| 자료 오독 | 자료 읽기 순서 드릴 | 자료 해석 훈련 |
| 발문 오독 | 발문 핵심어 터치 모드 | 발문 드릴 |
| 시간 부족 | 개념 즉답 퀴즈 강화 | 20초 제한 퀴즈 |

## 숙달도(단원 진행률)를 읽는 법

단원 카드의 막대는 **정답률이 아니라 개념별 숙달도의 분포**다. 색이 오른쪽으로 갈수록 단단해진다.

| 색 | 단계 | 조건 |
|---|---|---|
| 회색 | 미학습 | 아직 한 번도 안 나옴 |
| 빨강 | 불안정 | 틀렸거나 8초를 넘겨 맞힘 → 복습 큐에 있음 |
| 주황 | 학습 중 | 맞히기 시작함 (누적 정답 1~2회) |
| 노랑 | 익힘 | 누적 정답 3회 이상, 정답률 75% 이상 |
| 초록 | 완성 | 누적 정답 5회 이상, 정답률 90% 이상 |

퍼센트는 이 단계들의 평균이다. **모든 개념을 한 번씩 맞히면 정확히 50%**가 되고,
전부 ‘완성’이 되어야 100%가 된다. 한 번 맞힌 것과 시험장에서 72초 안에 바로 떠오르는 것은
다르기 때문에, 같은 개념을 여러 번·여러 방식(매칭·분류·즉답·모의고사)으로 맞혀야 올라간다.

단원 화면의 ‘숙달도’ 카드는 규칙만 설명하지 않고 **지금 무엇을 눌러야 하는지**를 알려 준다.

- **지금 할 일** — 가장 급한 단계 하나를 골라 이유와 함께 큰 버튼으로 띄운다.
  빨강이 있으면 복습 큐, 없으면 회색 → 주황 → 노랑 순으로 올라간다.
- **그 다음 순서** — 남은 단계와 각각에 맞는 화면 버튼
- **남은 분량** — “정답 49회 ≈ 매칭 게임 10판 또는 즉답 퀴즈 5판”처럼 판 수로 환산해 보여 준다

## 간격반복 규칙

- 오답 → 즉시 **불안정**으로 분류하고 **1일 뒤** 재출제
- 정답 → 1일 → 3일 → 7일로 간격을 늘림
- **서로 다른 날 3회 연속 정답**이면 큐에서 해제
- 정답이라도 **8초를 넘기면** 불안정으로 분류 (검정고시는 문항당 72초)
- 재출제 시 같은 개념이라도 **이전과 다른 사례**를 뽑는다

## 자료 문항의 근거 터치

자료 문항은 선택지만 고르면 제출되지 않는다. 그래프의 기온선·강수량 막대, 표의 해당 열,
피라미드의 해당 연령층처럼 **근거가 되는 부분을 눌러야** 제출 버튼이 열린다.
축·단위·범례를 확인하지 않고 찍는 습관을 막기 위한 장치다.
(실전 모의고사에서는 시간 측정을 왜곡하지 않도록 이 제약을 걸지 않는다.)

## 콘텐츠를 늘리는 방법

모든 콘텐츠는 `data/` 안의 평범한 JS 배열이다. 형식만 맞추면 프로그램 수정 없이 늘어난다.

```js
// data/cases.js — 사례 카드 한 장 추가
{ c:'c416',                          // 개념 id
  t:'낯선 장례 방식도 그 사회의 죽음관 속에서 의미를 파악해야 한다.',
  w:'맥락 속에서 이해하므로 문화 상대주의다.',   // 오답 시 보여 줄 한 줄
  k:'교과서' }                        // 또는 '시사'
```

사례를 추가하면 분류 게임·대비 문항·복습 큐가 **자동으로** 그 사례를 쓴다.
기출 문항은 `data/questions.js`에 같은 형식으로 붙이면 모의고사 풀에 바로 들어간다.

파일을 수정한 뒤 브라우저가 옛 파일을 계속 쓰면, `index.html` 안의 `?v=56` 숫자를 하나 올린다.

## 확인이 필요한 사항

기획서 말미의 미확인 항목은 프로그램으로 해결되지 않으므로 그대로 남겨 둔다.

- 2022 개정(통합사회1·2)의 검정고시 적용 연도
- 교과서 사례·자료 인용의 저작권 범위 — 현재 사례는 교과서 문장을 그대로 옮기지 않고
  개념을 설명하는 문장으로 새로 썼으나, 배포 전 검토가 필요하다
- 문항 검수를 맡을 사회 교사 확보
- 시사 사례는 분기마다 갱신 (`data/cases.js`에서 `k:'시사'`인 항목)
